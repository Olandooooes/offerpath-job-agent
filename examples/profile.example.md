# 个人求职配置样例

这是结构示例，放到仓库外后由使用者填写。未填写的条目不能被代理猜测，也不构成外发授权。

- 工作地点、远程与出差范围：由本人确定。
- 岗位方向、排除条件与经验门槛：由本人确定。
- 薪资硬下限、未披露薪资处理方式与对外报价口径：由本人确定。
- 岗位发布日期范围与例外：由本人确定。
- 已确认经历入口：指向自己的facts.md，逐条区分工作、实习、学习与个人项目。
- 已认可简历母版、语言及版式：指向自己的真实文件与认可记录。
- 正式状态源：本人OfferPath账户。
- 批次与证据目录：位于私有工作区。
- 未知必填事实：明确列出，查不到就暂存，不猜填。
- 联系方式：需要外发时定向读取，不放公共技能或仓库。

工作台记录当前关注事项，事实文件保存已确认经历及来源；历史状态最终与正式台账核对。
