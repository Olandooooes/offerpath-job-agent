# 千问办公连接器：本地合成验收

2026-10-24。此版本是面向千问办公桌面端的Skill及本地Streamable HTTP连接器；不是已上线的公共MCP服务。未购买模型API，未调用千问推理或真实招聘渠道，未使用作者私人资料或生产账户。

## 已验证

- 原有Codex执行器、配置向导和离线演示继续保留。
- 全套86项合成自动测试通过，包括原30项、MCP传输20项、远程接口适配12项、业务及真实回环HTTP闭环24项。
- MCP初始化、版本协商、工具发现、资料提案及真人事实确认、完整JD保存、按事实引用逐岗改写、真实PDF生成和资源下载。
- 人工审阅以独立浏览器会话、CSRF及精确版本/哈希绑定；普通MCP工具没有批准能力，读取资源不冒充真人看过PDF。
- 岗位别名不能解除未知结果锁；资料变更使未提交材料失效；历史密封申请可以仅补同步，不更改原附件或回执。
- 更换连接不继承旧目的地批准和预览；已申报且留档未完成的包，须本人重新审阅明确目标后恢复补同步。结果未知和已完成记录不能通过恢复转移。
- 模拟远程账户的记录/附件回读、重试幂等、现有面试状态和备注保留、下载损坏拦截，以及凭据/账号/Host/Origin隔离。

## 页面与独立前向验收

本地模拟MCP宿主为虚构集成岗选择接口接入、数据质量和管道测试事实，生成一页中文PDF；实际图片检查无缺字、重叠或裁切，Kubernetes生产经验保持缺口。模拟用户在本地卡确认精确PDF后，调用工具登记明确标注的合成结果并保存至本机假台账，重新下载比对字节与哈希，并检查实际留档PDF。

独立代理只获得技能、指定合成工作区和“产品岗只准备”的任务。它通过实际MCP协议生成产品专用PDF：突出用户访谈、需求分析及原型，商业化实习保持缺口；PDF为A4一页，资源下载字节与哈希一致，渲染检查通过。它没有代替本人确认、登记已投或同步记录。前向使用中发现的事实标题规则、0基索引和资源读取说明已补入schema和指南。

## 尚未验证与使用边界

- 当前开发机未安装千问办公；未验证其真实安装、工具发现、原生文件呈现或对话内真人确认，不能把协议测试称为客户端实机验收。
- 首版需要一次本地PDF审阅卡；尚无可靠证据支持直接采用千问端内的真人确认接口。AI不得代点真实材料确认。
- 真实OfferPath适配只通过本机假服务测试；正式账号独立授权是否对每位用户可用，须本人核对。未部署新的OAuth授权页。
- `complete`表示实际保存文件已下载回读并完成本地预览，不代表已检查OfferPath网站自身的预览界面，也不代表招聘方收到或处理了申请。
- 资料确认与事实ID/数字检查不证明全部内容真实；用户仍须逐项核对改写语义、针对性和最终PDF。客户端模型权益由其平台提供，本项目不承诺永久无限免费额度。

真实连接使用方法见[千问办公指南](../references/qwenwork.md)。个人配置、凭据、状态库、实际求职资料与验收截图均放在仓库外，不随本项目发布。
